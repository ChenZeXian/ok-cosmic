# 强制约束与验证策略

1. **拒绝幻觉**：严禁凭记忆或猜测生成任何 API 签名或单据字段标识。
2. **模板强制先行**：AI 在生成任何苍穹插件代码前，必须先读取对应的 `assets/*.java` 模板文件，并严格遵守模板中的方法签名。
3. **签名强制校验**：在编写任何 `@Override` 方法或调用 BOS SDK 关键方法前，必须执行 `cosmic-api-knowledge.py --config ok-cosmic.json detail "类全限定名"` 来验证该方法确实存在且签名准确。
4. **强制验证注释**：在生成的代码中，必须在每个涉及 BOS SDK 的方法（尤其是 `@Override` 方法）上方增加单行注释，明确标注验证来源。
   - **格式要求**: `// 验证来源: scripts/cosmic-api-knowledge.py detail [ClassName]`
5. **入口对齐协议**:
   - **UI 控制 (只读/隐藏/弹窗)**: 必须通过 `IFormView` (由 `this.getView()` 获取)。
   - **数据操作 (取值/赋值/结构)**: 必须通过 `IDataModel` (由 `this.getModel()` 获取)。
6. **验证优先级**：在使用原生 SDK 前，必须先查本地 `.md`，再通过脚本验证。
7. **继承溯源**：利用脚本返回的继承树确认方法是否在基类中。
8. **代码风格一致性**：必须符合 `assets/` 模板风格。
